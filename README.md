#  Online Student Marks Parent SMS Alerting System

A web-based application to improve communication between schools and parents regarding student performance.  
Teachers input student marks into a centralized database, and the system automatically sends **real-time SMS alerts** to parents when marks fall below a threshold.


##  Features
- Teachers can input student marks securely via a web interface.
- Automatic SMS alerts sent to parents for low marks.
- Real-time updates ensure timely communication.
- Reduces manual workload compared to traditional report cards.
- Accessible from any device with internet connectivity.
